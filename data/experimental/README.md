## 原始关系划分

三个文件逐字节保留原包的内容、顺序和边界，没有重新随机划分或改写关系/时间字段。

| 文件 | 关系行数 |

| `data/split/dev.jsonl` | 2,389 |

实际行结构为 `head, relation, tail, time, evidence_url, evidence_sentence`。三份划分并集与原 `data/collected/relations.jsonl` 的 23,895 条序列化记录集合一致。原始关系标签有 334 种，端点名称字符串有 16,029 个；这些不是全量图谱的稳定实体 ID 或 26 条核心谓词。`entity2id.txt` 等遗留映射按原字节保留，不把它们当作覆盖全部关系数据的已验证词表。

## 数据范围和已知限制

- 原 `time` 非空 13,537 行，空或未知 10,358 行。保留年份、月份、季度和自由文本，不把采集时间改成事件时间；不能按旧说明宣称 100% 时间覆盖。
- ISO 日字符串的最小/最大值为 1926-09-16 和 2031-04-06。这里只报告原数据值，不认定它们均为已发生事件；本子集也不冒充“截至 2025”快照。
- 原 train/dev/test 没有完全相同的序列化记录交叉重叠；按 `(head, relation, tail, time)` 比较，dev/test、dev/train、test/train 分别有 40、231、242 个交叉重叠组合，并共享来源 URL。原划分不能据此宣称无文档级或事实级泄漏。
- `data/collected/ie_dataset_clean.jsonl` 是独立的遗留联合抽取中间数据，共 6,030 条。在 16,987 个实体位置检查中，4,664 个 `text[start:end]` 与 `mention` 不一致，故保留原样供追溯，不作为已修复的金标准发布。
- 遗留采集输入文件 `data/batch_01.json` 不是合法 JSON，按原件保留；它不属于 train/dev/test 关系划分。
- JSON 语法、数量与跨度检查不证明关系事实、时间语义或人工标注质量。原数据不标为 human gold。
- 原包没有论文 PDF、DOI、BibTeX 或 LICENSE；不要自行补写论文归属或继承许可证。新闻正文及其他上游材料的权利仍属于各自权利人。

保留的少量遗留代码仅作为来源附录，不构成完整可运行采集系统；含凭据的采集器和本机路径预处理脚本已排除，也未用 stub 冒充可复现实现。
