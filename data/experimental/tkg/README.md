# ICKG-TKG

本目录说明时序知识图谱推理任务的数据归档要求。最终用于模型运行的按时间Train、Dev、Test文件及完整ID映射尚未归档，因此本目录暂不提供可用于复现论文成绩的划分文件。

已有[原始关系划分](../data/split/)继续保留，其字段为`head, relation, tail, time, evidence_url, evidence_sentence`。它的Train、Dev、Test时间范围交叉，不能直接作为按时间划分的TKG评测集。全量图谱的两个[知识快照](../../full/README.md)用于展示知识状态，也不等同于实验划分。

完整任务归档应同时提供：实际使用的四元组文件，覆盖全部记录的实体、关系与时间ID映射，固定时间边界及时间精度，未知时间与计划事实的处理规则，以及与该划分配套的过滤排序评价程序和运行配置。

归档后应从真实文件重新统计各集合数量，并在此说明其对应的模型运行与评价设置。
