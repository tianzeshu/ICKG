从产业脉络，走向知识证据

在四个工作区之间切换，逐步查看产业结构、实体关联与原始来源。

  1. 图谱探索点击要素卡片高亮关联层；切换“实体网络”查看具体实体。
  2. 产业全景浏览产业环节和行业分类，点击行业查看关联企业。
  3. 关系溯源选择关系记录，查看事件时间、公开时间与原文证据。
  4. 实体索引按类型查找实体，或用顶部搜索直接定位。
时间探索支持“事件 / 有效时间”和“公开 / 观测时间”。数据概览统计当前知识快照，工作区内容受筛选条件影响。
